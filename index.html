About

关于我

我是王跃凯，金融数学背景（南方科技大学本科，香港城市大学硕士在读），正在向游戏策划方向转型，主攻数值策划 / 系统策划。金融建模训练给了我扎实的数据与系统化思维——这正是游戏数值设计「设计—测试—复盘—调优」所需要的同一套能力。

作为重度卡牌玩家，我对构筑、数值平衡与风险收益博弈有第一线的实战理解；同时我也在用 Godot 独立开发自己的卡牌 Roguelike（已设计 1,000+ 张卡牌，计划 2026 年上线 Steam）、做卡牌构筑教学自媒体，并把对经典游戏的拆解整理成设计文档。

数值 / 数据

精通 Excel 数据建模与平衡测算，了解 Python / MATLAB 基础；可独立完成数值配置、资源核算与平衡迭代。

系统 / 文档

擅长游戏系统拆解与策划文档撰写，能把复杂机制结构化、清晰表达；具备系统化设计思维。

引擎 / 工具

使用 Godot 独立开发游戏，掌握 GDScript 基础；熟练运用 Codex、Claude 及 AI 生图 / 生成音乐工具提效。

玩家视角

卡牌 Roguelike（独立游戏）

主策划 / 独立开发 · Godot 引擎
  • 基于 Godot 从 0 独立开发的单机卡牌 Roguelike：主导战斗循环与卡牌构筑核心机制，搭建卡牌、怪物、战利品掉落的全链路数值框架，自研数值配置表并完成多轮平衡性调优。
  • 累计完成 1,000+ 张卡牌设计，持续迭代怪物 AI 与多层关卡流程，精准把控难度梯度、卡牌收益与博弈风险。
  • 输出全套系统设计与数值规范文档，覆盖战斗规则、经济产出—消耗循环、流派 Build 成长体系。
  • 借助 Claude、代码 AI 与 AI 美术 / 音频工具独立完成脚本、原画、BGM 与音效，计划 2026 年内推出可对外测试版本并上线 Steam。
